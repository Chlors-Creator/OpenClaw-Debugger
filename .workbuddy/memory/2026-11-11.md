## 2026-11-11 追加：Xcode 与壳路线的最终结论

- **Xcode 实际已安装**：`/Applications/Xcode.app`，Xcode 27.2（27B52），许可已接受，
  macOS SDK 27.2。`xcode-select -p` 指向 `/Library/Developer/CommandLineTools`，

- **结论：仍保持 Avalonia 壳，不改原生 AppKit。** 依据：两者都跑 WKWebView，
  差异只在壳的形态（包体、原生菜单、App Store 沙箱）；而本项目的风险在桥接装配、
  Keychain/SSH 验证、文件选择通道，不在壳。换壳会把时间花在不产生功能的地方。
  触发再评估的条件：要上 Mac App Store / 需要菜单栏常驻与自动更新 / 包体敏感 /
  Avalonia WebView 在拖拽或输入法上出问题。迁移成本低（`IBridgeTransport` 已抽象）。
- 待确认：`Avalonia.Controls.WebView` 文档挂在 Accelerate（商业线）下，
  nuspec 声明 MIT，正式分发前需核实授权条款。
